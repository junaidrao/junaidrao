# Junaid Iqbal

NetSuite and integration engineer. I run [Byterive](https://github.com/Byterive), a NetSuite and integration studio.

I have built or worked on 900+ SuiteScript files across 35+ clients, over 6+ years on NetSuite. Most of my work now is moving SuiteScript 1.0 and 2.0 scripts to 2.1, and fixing the habits that make old scripts slow and fragile on the way.

## What I work on

- **SuiteScript 2.1 migration.** Audit, risk ranking, rewrite, sandbox testing and staged release.
- **NetSuite development.** User events, Suitelets, Map/Reduce, RESTlets and SuiteQL.
- **Integrations.** Celigo and Boomi flows, EDI flows on Celigo (X12 and EDIFACT), and CRM and storefront sync.
- **Backend services.** Go, Node.js and Python, for the jobs a connector can't do.

Client code stays private. What I publish here is written from scratch.

## Open source

Claude Code plugins I build at Byterive, shared through one marketplace, [Byterive kit](https://github.com/Byterive/kit):

| Plugin | What it does |
|---|---|
| [kickoff](https://github.com/Byterive/kickoff) | Starts a project in one command and picks it up again next session |
| [guidebook](https://github.com/Byterive/guidebook) | Turns a project into plain-language guides and refreshes them when the project changes |
| [unity-game-kit](https://github.com/Byterive/unity-game-kit) | Sets up a Unity game the same way every time and tells you what is missing |
| [idea2spec](https://github.com/Byterive/idea2spec) | Tests an idea before you build it, and writes a spec only on GO |
| [cachepulse](https://github.com/Byterive/cachepulse) | Shows whether Claude Code reused its prompt cache, and why not |
